# WELO

Welo is a tiny Weather pet or weather assistant shaped like a cat that shows time, weather and cool animations all controlled through it's touch sensor/pat like it changes the mode when u pat it.

# What it is?

Welo is a tiny 80x55x65 pet assistant that can display weather, time as well as cool stuff...(Even loves you when u love it or pat it..hehe)..

# How it works?

Welo uses a ESP32, 1.3inch OLED and a TTP223...it get's it power directly from the micro-usb port in the ESP, and has api initilized in it's code that runs everything and switches mode...When someone pats on the head of the pet robot then it is detected by the TTP223 and thus changes the mode and give a cute feel..


# Why it was made?

It was made as  I notied that people pick up their phone to see weather and end up into hours of doom scrolling..(I myself face this a lot)..Thenn i told myself 'Why to settle for less?' and thus decided to give it a look of cat which makes it cool and cute..I even added a clock here as seeing time in wall clocks is not that cool..This is how WELO came out..

# How to Build it?

**To replicate Welo, follow the below mentioned steps:**
1) First, go grab the CAD from the CAD folder..or you can download the files from [here](https://drive.google.com/drive/folders/1-Gn5eq_jPVh20CZxeo8vWbvCTA9HpXYL?usp=sharing). I prefer going to the CAD folder and go through the CAD.md for detailed understanding of the CAD.
2) Then grab the parts mentioned in the [BOM](https://github.com/AayanKhan949/Welo/tree/main/BOM)..
3) Wire up the electronics as per the [Circuit Diagram](https://github.com/AayanKhan949/Welo/tree/main/Circuit-Diagram).
4) Then assemble everything in the 3D shell as per the completely assemble .step file of the CAD
